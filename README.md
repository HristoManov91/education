# Education

Лична, изпълнима Java/Spring инженерна knowledge base с примери, тестове и обяснения на български език.

Целта на repository-то не е да събира копирани snippets, а да превръща полезни материали от видеа, документации и реални production проблеми в малки лаборатории, които могат да бъдат стартирани, променяни и доказвани с тестове.

## Основни правила

- Кодът, имената на класове, методи, полета и package-и са на английски.
- README документацията и обяснителните коментари са на български.
- Всеки пример трябва да показва **какъв проблем решава**, **защо възниква**, **как можем да го докажем** и **как изглежда доброто решение**.
- Когато е полезно, пазим `bad` и `good` вариант за директно сравнение.
- Примерите в `src/main` са production-like; тестовете и експериментите са в `src/test`.
- За persistence/database теми, когато е практично, примерите трябва да разглеждат PostgreSQL и Oracle и да описват специфичните разлики.
- За подходящи теми може да има `exercise` и `solution` варианти.
- Използваме Java 25 като основна LTS версия и актуална съвместима Spring Boot 4.x версия.

## Правило за източниците

**Всеки учебен модул задължително съдържа секция `Оригинални източници`.**

Там се пазят директни линкове към материалите, от които е тръгнала темата, например:

1. оригиналното видео / статия / книга;
2. оригиналният примерен GitHub repository, ако има такъв;
3. официалната документация;
4. съответните JEP / RFC / specification документи;
5. допълнителни първични източници, използвани за актуализиране или проверка на материала.

Когато оригиналният материал използва по-стара версия на Java, Spring или библиотека, нашият пример може да бъде актуализиран, но README трябва ясно да обяснява разликата и да запази линка към оригинала.
