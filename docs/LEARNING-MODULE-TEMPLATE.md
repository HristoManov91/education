# Име на темата

## Какво ще научим

Кратък списък с конкретните инженерни знания, които лабораторията демонстрира.

## README → код

> Тази секция е задължителна за всеки учебен модул.

Направи кратка карта между основните концепции в README и конкретните файлове, които ги демонстрират. Използвай **относителни Markdown линкове**, за да работят и след clone на repository-то.

Пример:

| Концепция | Production-like пример | Доказателство / тест |
| --- | --- | --- |
| Основна техника | [`ExampleService.java`](./src/main/java/.../ExampleService.java) | [`ExampleServiceTest.java`](./src/test/java/.../ExampleServiceTest.java) |
| Конфигурация | [`application.properties`](./src/main/resources/application.properties) | — |

Освен тази карта, когато даден README раздел обяснява конкретен implementation detail, добави локален линк до съответния class/config/test непосредствено в раздела.

В самия Java код не копирай цялото обяснение от README. Коментарите трябва да обясняват нетривиалното **„защо“**, lifecycle, constraints или behavior, което не се вижда очевидно от самия код.
