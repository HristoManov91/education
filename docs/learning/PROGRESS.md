## Дневник на заниманията

### 2026-10-09 · Q5 — numeric conversions & overflow (част 1, продължава)

**Зададен код:** `int max = Integer.MAX_VALUE; long a = max + 1; long b = (long) max + 1; byte count = 127; count += 1;`.

- **Отговор:** кодът се компилира; правилно предвидени трите реда: `-2147483648`, `2147483648`, `-128`.
- **Механизъм:** правилно описани `int` overflow преди присвояване към `long`, и изричният cast преди събиране при втория израз.
- **Терминология:** при разширяване `int → long` използвай *widening primitive conversion*; обратното е *narrowing primitive conversion*. Не е нужно да се помни наизуст `Integer.MAX_VALUE`. `byte` има 8 бита и 256 стойности, не „е 256“.
- **Все още непроверено:** защо `count += 1` се компилира, какъв е типът на `count + 1` и как се различава `count = count + 1`. Ученикът поиска насочване, затова **не публикувай решението преди отговора му**.
- **Статус:** част 1 остава **IN_PROGRESS**, без окончателна техническа/комуникационна оценка или статус MASTERED. Autoboxing още не е зададен.
- **Следваща проверка:** мини-проба с разлика между `count += 1` и `count = count + 1`; след реалния отговор — feedback, тематична Concept Note и бъдещи recall дати.
