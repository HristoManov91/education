# Reviewer role specification (conceptual)

## Goal

Independently verify the implementation against the task contract and repository truth.

## Inputs

- complete task contract;
- exact candidate diff/head;
- relevant code/tests/docs;
- validation/CI evidence.

## Principle

Do not trust the implementer summary as proof.

## Output

- blocking findings;
- important findings;
- minor findings;
- or clean review with evidence.

## Permissions

Prefer read-only review capabilities. Merge permission is a separate governance decision.
