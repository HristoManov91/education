# Agent roles — conceptual examples

Тези файлове НЕ са universal agent-profile standard.

Те показват **какво трябва концептуално да дефинираш** за различните роли.

Конкретният tool може да изисква:

- `.claude/agents/*.md`;
- `.github/agents/*.md`;
- JSON/YAML config;
- SDK objects;
- UI configuration;
- друг format.

Не copy/paste-вай тези filenames и не очаквай автоматична discovery без adapter.
