# Task handoff template

Това е учебен пример за **portable transfer snapshot**. Не е source of truth и не е universal AI standard.

```text
Repository:
<owner/repo>

Task:
<issue/task contract>

Goal:
<short outcome>

Current workflow state:
<state>

Current candidate:
<branch / PR / exact head SHA>

Done:
- ...

Locked decisions:
- ...

Validation/evidence:
- ...

Open findings / blockers:
- ...

Relevant files/docs:
- ...

Next action:
- ...

Do not:
- create duplicate task/PR
- reinterpret locked decisions
- trust this snapshot over newer repository state
```

Receiving agent трябва първо да reconcile-не snapshot-а срещу current Issue/PR/head/code/CI.
